📡 API Endpoints

GET /api/services/
Получить список всех услуг
Пример ответа: 
[]
GET /api/services/<slug>/
Получить детали услуги по slug
Пример ответа: 
{"title": "Услуга", "description": "Описание"}
GET /api/cases/
Получить список всех кейсов
Пример ответа: 
[]
GET /api/cases/<slug>/
Получить детали кейса по slug
Пример ответа: 
{"title": "Кейс", "description": "Описание"}
GET /api/pricing/
Получить список тарифных планов
Пример ответа: 
[]
GET /api/faq/
Получить список часто задаваемых вопросов
Пример ответа: 
[]
GET /api/contacts/
Получить контактную информацию компании
Пример ответа: 
{"company_name": "Компания", "email": "email@example.com"}
POST /api/contacts/send/
Отправить форму обратной связи
Пример ответа: 
{"ok": true, "sent": true}
Обязательные поля: name, message
GET /api/pages/<slug>/
Получить SEO данные страницы
Пример ответа: 
{"title": "Заголовок", "meta_description": "Описание"}

💡 Примеры использования

get_services:
curl http://localhost:8000/api/services/
get_contact_info:
curl http://localhost:8000/api/contacts/
send_feedback:
curl -X POST http://localhost:8000/api/contacts/send/ -H 'Content-Type: application/json' -d '{"name": "Имя", "message": "Сообщение"}'
